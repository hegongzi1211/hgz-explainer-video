# 内容怎么写（算账型科普视频公式）

这个版式（真人小窗 + 信息图 + 波形字幕）不是通用口播模板，它最适合 **「帮你算一笔账」类** 的知识科普——把读者模糊的认知，用具体数字砸实。

## 核心套路：反共识 + 算账 + 双比喻

读者本来「以为自己懂」，你先认同、再打破、再给新框架。

```
钩子（30s）  复述用户原问题，制造群体共鸣
             「你这个问题特别典型，XX 的朋友十有八九都这么想」
原理（30s）  一句话击穿认知盲点
             「问题就出在 XX 这四个字里」
算账（每段） 场景 → 总花费 → 已覆盖 → 缺口 → 补救
             每段 ≥3 个具体数字（精确到元）
转折         观众自问自答，制造「原来如此」的顿悟
             「我的天，原来是这样」/「这点我之前真没想到」
金句（30s）  双比喻收口，锁死记忆
             「XX 是基础盘，YY 是升级包」
CTA（30s）   「如果你也是 XX，关注我，下期接着算」
```

## 每个场景写什么

`content.json` 里一个 `scene` = 一段口播 + 一张信息图。字段对应：

| 字段 | 写什么 | 注意 |
|------|--------|------|
| `narration` | 这段口播原文（TTS 读它） | 口语化，别写书面长句；Voicebox 念拗口字会校验多轮 |
| `cardHeadline` | 信息图主标语（大白字） | ≤14 字，一句结论 |
| `cardSubline` | 信息图副标语（灰字） | 补充说明，可空 |
| `cardLayout` | 信息图版式 | `pyramid`/`flow`/`grid4`/`ring`/`image` |
| `tags` | 标签条（最多 3 个） | 黄底黑字，放关键词 |
| `subtitle` | 屏幕字幕 | 是 `narration` 的**精简版**，一行能念完 |

> 关键：字幕 ≠ 口播全文。字幕是「这一屏观众该记住的那句话」，口播是展开讲。两者一起念才不违和。

## 4 种版式怎么选

| 版式 | 用它讲什么 | 例子 |
|------|-----------|------|
| `pyramid` | 层级 / 体系叠加 | 「你的保障是两层叠加」「医保三层」 |
| `flow` | 算账 / 资金流向 | 「总花费 10 万 → 报 7 万 → 自掏 3 万」 |
| `grid4` | 并列清单 | 「4 个不报的场景」 |
| `ring` | 闭环收口 | 「不是二选一，是基础 + 升级」 |
| `image` | 现成图 | 配 `cardImageSrc`，放 `public/` |

## 算账的数字纪律

这条视频能不能火，看数字真不真：

- **每个场景至少 3 个具体数字**，精确到元 / 百分比
- 给「总 → 已覆盖 → 缺口」三段式，缺口就是商业险出场的位置
- 别编离谱数字，读者会算；用公开可查的区间（如靶向药月费用、封顶线）

## 可复用的迁移思路（给学员的钩子）

这套框架不只能讲保险，任何「基础能力 vs 进阶能力」的主题都能套：

- AI 工具方向：「免费 AI 是基础包，私域/课程是升级包」
- 理财方向：「存款是底，基金/保险是补」
- 职场方向：「工资是基础盘，副业是升级包」

写稿时把「基础盘 / 升级包」比喻换成你领域的两个东西，结构直接复用。
